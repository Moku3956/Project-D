# システム仕様

## 目的

SQLおよびDBMSの内部動作を学ぶための教育用システム。

既存の学習サービスはSQLの書き方は教えてくれるが、「なぜそう動くのか」「内部でどう処理されているのか」は教えてくれない。本システムはSQLを実行したときにDBMSの内部で何が起きているかをリアルタイムに可視化することで、ユーザーがDBMSの仕組みを直感的に理解できるようにする。

---

## システム概要

本システムは2つの役割を持つ。

**1. DBMSコア**

GoのライブラリとしてSQLの実行・データの永続化を担う。CLIツールや他のアプリからも単体で利用できる。

**2. SQL学習サイト**

DBMSコアをバックエンドとして動かし、SQLをパースしてからディスクに保存されるまでの各処理ステップをブラウザ上でリアルタイムに図解する。ユーザーはSQLを投げるだけで、字句解析・構文解析・実行計画・ストレージへの書き込みまでの流れを視覚的に追うことができる。

---

## DBMSの概要

### サポートするSQL

標準SQLのサブセットをサポートする。

- **DDL**: `CREATE TABLE`、`DROP TABLE`
- **DML**: `SELECT`、`INSERT`、`UPDATE`、`DELETE`
- **トランザクション**: `BEGIN`、`COMMIT`、`ROLLBACK`
- **データ型**: `INT`、`VARCHAR(n)`、`BOOLEAN`
- **制約**: `PRIMARY KEY`、`NOT NULL`
- **句**: `WHERE`、`INNER JOIN`、`ORDER BY`、`LIMIT`
- **演算子**: 比較演算子、論理演算子、`IS NULL` / `IS NOT NULL`

サポートする構文は今後拡張可能な設計にする。

### ストレージ

B+Treeをベースにしたディスクベースのストレージエンジン。データはファイルに永続化される。クラッシュ後もWAL（Write-Ahead Log）によってデータの整合性を保証する。

### トランザクション

1トランザクション = 1クライアントからの操作単位。コミット済みのトランザクションはクラッシュ後も復旧できる。ROLLBACKによる取り消しも可能。

### 並行制御

複数ユーザーからの同時アクセスをサポートする。読み取りは複数同時に実行できる。書き込みはテーブル単位で排他制御する。

---

## 学習サイトの概要

ユーザーがSQLを入力すると、以下のステップがリアルタイムに可視化される。

```
SQL文字列
  → 字句解析（Lexer）   : SQL文字列をトークンに分解
  → 構文解析（Parser）  : トークンを構文木（AST）に変換
  → 実行計画（Planner） : どう実行するかを決定
  → 実行（Executor）    : 実行計画をもとにデータを操作
  → ストレージ          : ディスクへの読み書き
```

各ステップの処理内容・入出力をブラウザ上でアニメーションや図として表示する。

### ユーザー分離

学習サイトではユーザーごとに独立したDB環境を持つ。あるユーザーの操作が他のユーザーに影響することはない。
